# 부하 테스트 결과

`scripts/loadtest/`의 k6 스크립트로 수행한 부하 테스트 결과와 분석을 이 디렉터리에 기록합니다.

## 파일 작성 규칙

파일명: `YYYY-MM-DD-<시나리오명>.md` (예: `2026-09-20-baseline-300users.md`)

각 리포트는 아래 항목을 포함합니다.

1. **시나리오** — VU 수, 지속 시간, 요청 패턴
2. **환경** — 테스트 시점의 인프라 구성 (인스턴스 수, 리소스 제한 등)
3. **결과 지표** — RPS, p95/p99 latency, 에러율
4. **병목 분석** — CPU/메모리/DB 커넥션 등 어디서 한계가 나타났는가
5. **개선 조치 및 재검증 결과**
