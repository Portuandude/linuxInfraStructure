# 장애 리포트

의도적으로 주입한 장애와 실제 발생한 이슈에 대한 대응 기록을 이 디렉터리에 남깁니다.

## 파일 작성 규칙

파일명: `YYYY-MM-DD-<짧은-제목>.md`

각 리포트는 아래 항목을 포함합니다.

1. **개요** — 무슨 장애가 발생했는가
2. **탐지** — 어떻게, 언제 알아챘는가 (모니터링 알림 / 사용자 보고 등)
3. **영향 범위** — 어떤 서비스/사용자가 영향받았는가
4. **원인 분석** — 근본 원인
5. **대응 조치** — 실제로 취한 조치와 타임라인
6. **재발 방지책** — 이후 적용한 개선 사항
